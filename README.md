# Pelican on a Bike

A collection of CSS animation tests: each file is a different AI model's attempt at drawing a pelican riding a bicycle.

## View the gallery

Open [index.html](index.html) locally, or visit the GitHub Pages site once published.

## Adding a new test

1. Add your `.html` file to the repo root.
2. Add an entry to the `tests` array in `index.html`.
3. Commit and push — the site updates automatically via GitHub Pages.

## GitHub Pages

This repo is set up for GitHub Pages from the `main` branch (root). After pushing, enable Pages under **Settings → Pages → Deploy from branch → main / (root)**.
